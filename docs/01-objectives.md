# 01 — Project Objectives and Scope

## 1. Purpose

The purpose of this project is to establish a functional virtual cybersecurity laboratory using Oracle VirtualBox and Kali Linux.

The environment provides a foundation for subsequent cybersecurity exercises involving networking, reconnaissance, traffic analysis, vulnerability assessment, and security testing.

## 2. Primary Objectives

1. Install and verify Oracle VirtualBox.
2. Import and configure the Kali Linux virtual machine.
3. Create a dedicated VirtualBox NAT Network.
4. Assign a static IPv4 address to Kali Linux.
5. Configure the default gateway and DNS server.
6. Verify local gateway connectivity.
7. Verify external network connectivity.
8. Verify DNS resolution.
9. Configure shared-folder integration between Windows and Kali.
10. Enable bidirectional clipboard and drag-and-drop settings.
11. Create a baseline VM snapshot.
12. Maintain screenshot evidence and technical documentation.

## 4. Planned Extensions

The following are planned activities and are not part of the completed Kali setup:

- Android-x86 VM deployment.
- Windows 10 VM deployment.
- Inter-VM communication tests.
- Wireshark practical exercises.

## 5. Expected Outcomes

At the end of the current phase, the lab should provide:

- A bootable Kali Linux VM.
- A predictable static IPv4 configuration.
- Working gateway and external connectivity.
- Functional DNS resolution.
- Verified host-to-guest shared-folder access.
- A recoverable baseline snapshot.
- Reproducible configuration documentation.

## 6. Authorization and Safety

All future security testing must remain within the designated lab environment or other explicitly authorized systems.

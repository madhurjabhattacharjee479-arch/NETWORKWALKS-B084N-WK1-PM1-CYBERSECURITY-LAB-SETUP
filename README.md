# NetworkWalks — Cybersecurity Lab Environment Setup

**Batch ID:** B084N
**Project:** Week 1 — Project Module 1
**Status:** In Progress

## Overview

This repository documents the setup, configuration, and verification of a cybersecurity practical lab environment using Oracle VirtualBox and Kali Linux.

## Objectives

- Configure a Kali Linux virtual machine.
- Configure a VirtualBox NAT Network.
- Assign the required static IPv4 configuration.
- Establish internet connectivity and DNS resolution.
- Configure clipboard, drag-and-drop, and shared-folder integration.
- Document verification results and troubleshooting.

## Target Network Configuration

| Component | Target configuration |
|---|---|
| Network mode | NAT Network |
| Subnet | 10.0.0.0/24 |
| Kali IPv4 | 10.0.0.2/24 |
| Default gateway | 10.0.0.1 |
| Shared folder mount point | /downloads |

These are the guide's target values. Actual implementation and verification results will be documented separately.
